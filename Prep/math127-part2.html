🛠️ Senior Front-End Developer Maintenance Guide

This application is architected to be 100% extensible via a single JavaScript object array (TOPICS_DATA). No manual HTML duplication is needed to expand the module.

a) How to Add a New Category / Topic

Open the <script> block at the bottom of this file and append a new object to TOPICS_DATA using this pattern:

{
    id: "unique_topic_id",
    category: "Category Name (e.g., 1. Exponents & Polynomials)",
    title: "Topic Name",
    concept: "Markdown or standard text with LaTeX formulas like \\( x^2 + y^2 = r^2 \\).",
    pitfall: "Common student traps on ALEKS.",
    example: {
        problem: "Step-by-step example problem statement.",
        steps: ["Step 1 explanation", "Step 2 equation"]
    },
    practice: {
        problem: "Interactive question prompt.",
        answer: "42", // String expected for exact checking
        hint: "Step-by-step solution to reveal if requested."
    }
}

b) How LaTeX Rendering Works

This file utilizes KaTeX auto-render. Write inline formulas using \( ... \) and block display equations using $$ ... $$ inside any string field in TOPICS_DATA. KaTeX automatically renders them upon dynamic mounting.

c) State Management Architecture

Topic completion checkboxes persist state using localStorage under the key aleks_mastery_state. Toggling any checkbox updates the state array and triggers a reactive calculation of the sticky navigation progress percentage.
